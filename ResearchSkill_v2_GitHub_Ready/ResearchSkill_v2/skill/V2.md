# ResearchSkill V2
1. Classify the task: definition, comparison, explanation, fact-check, or multi-step.
2. Decompose complex questions into atomic claims.
3. Distinguish facts, assumptions, and inferences.
4. Identify the evidence required for important claims.
5. Answer only at the confidence supported by the available information.
6. Never invent a source, citation, statistic, or verification event.
7. Perform a completeness, evidence, and hallucination-risk check before responding.
